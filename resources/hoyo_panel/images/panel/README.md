# 自定义面板图目录

原神 / 星铁单角色面板的立绘，按下面顺序取，取到就用：

1. **咕咕牛管理器**：`plugins/miao-plugin/resources/profile/normal-character/<角色名>/`
   （由咕咕牛图库管理器部署，一个角色多张时随机取一张）
2. **本目录**：`resources/hoyo_panel/images/panel/<gs|sr>/<角色名>/`
3. 官方立绘（游戏原图）

## 目录结构

```
resources/hoyo_panel/images/panel/
├── gs/              原神
│   ├── 雷电将军/
│   │   ├── 1.webp
│   │   └── 2.png
│   └── 胡桃/
└── sr/              星铁
    └── 遐蝶/
        └── x.webp
```

- 文件夹名 = 角色正式名（如 `雷电将军`、`遐蝶`），简称不行；`「名字」` 这种带引号的写法也认
- 支持 `png` / `jpg` / `jpeg` / `webp`
- 一个角色放多张时每次出图随机取一张

## 指令（只有主人能用）

| 指令 | 作用 |
| --- | --- |
| `#米哈游上传雷神面板图` + 附图（或引用图片） | 存到对应角色目录 |
| `#米哈游查看雷神面板图 [页码]` | 列出已上传的图，带 ID |
| `#米哈游删除雷神面板图 1,2` | 按 ID 删除 |

星铁角色可以写 `#米哈游上传星铁遐蝶面板图`。

## 左侧二维码栏

咕咕牛图库导出的图左侧带二维码/编号/来源栏，直接当立绘会露出来。
插件出图前会按 `panel_custom_art_crop` 的比例裁掉左侧（默认 `0.24`，
1280 宽的图约 307px，正好切在二维码栏右缘），裁切结果缓存在
`resources/hoyo_panel/images/panel_crop/`。

- 想保留完整图：把 `panel_custom_art_crop` 设为 `0`
- 想始终用官方立绘：把 `panel_custom_art` 设为 `false`
